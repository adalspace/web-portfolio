02 Open source · Video demo

Cheetah

A strongly typed automation language and interpreter written in C++.

Cheetah is designed for fast desktop automation without giving up explicit types or native extensibility. I built the lexer, parser, runtime, type system, generics, standard-library foundations, and support for loading C++ modules directly.

  • Strict type handling with deliberate casting and structured language features.
  • Native C++ extension model for performance-sensitive automation modules.
  • Cross-platform CMake workflow with continuous integration through GitHub Actions.
